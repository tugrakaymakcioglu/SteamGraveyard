# SteamGraveyard 1.1.0 — Guided Discovery

Released August 9, 2026

SteamGraveyard 1.1 makes the project substantially easier to start, safer to
configure, and clearer to explore. This release adds a guided first-run
experience, content categories, secure API-key handling, and direct research
links while preserving the project's conservative approach to Steam licenses
and catalog evidence.

## Highlights

### Guided first-run setup

New users are welcomed by an in-terminal setup screen that explains where to
obtain a Steam Web API key and how it is used. Keys are format-checked, then
verified through a small read-only request before a catalog update begins.

Validated keys are stored in the operating system credential vault when a
supported backend is available. If secure storage is unavailable, the key is
kept only for the current session. SteamGraveyard never asks for a Steam
password, session cookie, or account token.

### A catalog organized for discovery

The terminal interface now separates the catalog into focused views:

- Games
- DLC
- Curated demos
- Verified free titles
- Delisted titles

Every row and detail view displays its content type. The official Steam catalog
update now retrieves games and DLC independently, then applies both only after
the complete scan passes validation and safety checks.

### Safer Steam actions

Verified entries can expose an **Add / Open in Steam** action through Steam's
official URI handler. The action remains disabled unless the record has an
eligible claim status, a supported activation method, and a validated positive
AppID or SubID. Steam remains the final authority on license and installation
availability.

Each detail view also provides explicit links to the Steam Store and the
corresponding SteamDB research page. These links open only after a user action;
SteamGraveyard does not scrape or automate SteamDB.

### One-click Windows startup

Windows users running the source release can now double-click
`START_STEAM_GRAVEYARD.bat`. The launcher checks Python, creates an isolated
environment, installs the project, and starts the application. Re-running it is
safe and updates the local installation from the current checkout.

## Data and trust improvements

- The starter dataset now includes source-verified free entries for Team
  Fortress 2, Counter-Strike 2, and the We Were Here Tomorrow Demo.
- LawBreakers remains `UNKNOWN` for claimability. A historical shutdown notice
  is not treated as proof of present-day license availability.
- Content type is now part of the validated model, database queries, exports,
  scan diffs, and terminal output.
- Curated demos are protected from false delisting transitions because the
  official catalog endpoint does not provide an equivalent demo filter.
- API keys are excluded from SQLite, exports, logs, and command output.
- Existing databases migrate in place. Corrupt databases are still preserved
  for manual recovery instead of being deleted automatically.

## Command-line additions

```console
steam-graveyard setup
steam-graveyard category games
steam-graveyard category dlc
steam-graveyard category demos
steam-graveyard category free
steam-graveyard category delisted
steam-graveyard forget-key
```

## Upgrading

If you use a source checkout:

```console
git pull --ff-only
START_STEAM_GRAVEYARD.bat
```

If you installed the package from a GitHub release:

```console
python -m pip install --upgrade https://github.com/tugrakaymakcioglu/SteamGraveyard/releases/download/v1.1.0/steam_graveyard-1.1.0-py3-none-any.whl
steam-graveyard
```

The database migration runs automatically on first start. No destructive reset
is required.

## Known boundaries

- A Steam Web API key is required to refresh the current games and DLC catalog.
  Offline browsing remains available without one.
- Steam's documented catalog endpoint does not provide the same first-class
  demo filter, so demo records are curated and evidence-backed.
- SteamDB has no public API for this use case and prohibits automated scraping.
  It is available only as an explicit research link.
- SteamKit/PICS can support a future autonomous enrichment service, but hidden
  or deleted records may still require package or app access tokens. It is not
  bundled into this beginner-focused desktop release.
- No live full-catalog refresh was represented as release evidence because no
  Steam API key is present in the build environment.

Thank you for helping build a more transparent, evidence-based history of the
Steam catalog.
